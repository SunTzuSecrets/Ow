# suntzusecrets.com home page

Static home page of the Sun-Tzu Secrets channel (EN/IT), served from the root of suntzusecrets.com.
Upload the contents of this folder to `public_html/`.

The campaign portal ("Le Ombre sulla Baia dei Relitti") lives on https://campagna.suntzusecrets.com/.
Old links like `suntzusecrets.com/#/...` are redirected there by a small script in `index.html`.
